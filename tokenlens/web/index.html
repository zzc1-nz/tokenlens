模拟器

用真实 HTTP 流量压测整条管道：采集 → 计价 → 存储 → 聚合 → 预算 / 异常

生成负载

在仓库根目录执行。所有流量都走公开的 POST /api/v1/ingest/snapshots， 每批最多 500 条快照，带 event_id 保证幂等。 

python tools/simulate.py --server http://127.0.0.1:8787 \
  --mode mixed --duration 60 --agents 6 --projects 4 \
  --sessions 40 --target-tokens 1000000 --seed 42 --report

先把服务跑起来：

python -m uvicorn tokenlens.app:app --port 8787

注入异常

--mode incident 会同时注入三类根因，让检测器有东西可找： 重试风暴（高重试率）、上下文膨胀（超大 context_window）、工具返回未压缩（超大 tool_result_bytes）。 

python tools/simulate.py --server http://127.0.0.1:8787 \
  --mode incident --duration 45 --agents 3 --seed 7 \
  --inject anomalies --report

然后用 curl 触发检测：

curl -X POST "http://127.0.0.1:8787/api/v1/anomalies/detect?lookback_minutes=60"

参数速查

参数说明
--modeburst / steady / incident / mixed
--duration持续时间（秒）
--agents / --projects / --sessions并发维度规模
--target-tokens达到目标 token 数后停止
--concurrencyHTTP 并发数
--seed随机种子，保证可复现
--dry-run只生成不发请求（可单测）
--report打印吞吐量：snapshots/s、tokens/s、accepted/duplicates

命令行客户端

同样的数据也能在终端里看，适合 SSH / CI 场景：

tokenlens hud      --server http://127.0.0.1:8787 --interval 1.0
tokenlens summary  --server http://127.0.0.1:8787
tokenlens breakdown --dimension agent
tokenlens detect   --lookback 60 --evaluate-budgets
